## Discrepancy analysis

The e2e delta is explained by the uncommitted work itself: the untracked `playwright.config.ts` (30 s test timeout, proper vite webServer boot on 5183) and the hardened boot sequence are part of the dirty worktree. In the Phase 0 re-run the entry-path tests pass but take **14–27 s each** — first-run garment generation still blocks entry; the tests now merely outlast it.

**Standing conclusion (unchanged):** blocking entry on first-run sample-garment generation is a design defect. The rebuild's entry acceptance criteria (plan §9.1) — "no first-run task blocks the Enter or Open action", "do not generate demo garments during boot" — remain a priority requirement, independent of today's green suite.

## Improvement targets this baseline anchors

- E2E entry tests should complete in ~2–3 s once boot no longer blocks on garment prep.
- Three.js must not load in ordinary 2D route bundles (plan §11); the 2D shell must be interactive without the 3D bundle (plan §16).
- Bundle re-measured at every phase gate against this table.
