# the-wardrobe

The Wardrobe is a production-oriented personal wardrobe app built with React, Three.js (React Three Fiber), and TypeScript, combining a cinematic 3D main menu with fast, task-focused 2D workspaces for everyday use. It lets you photograph and cut out real garments, save them to a private cloud-backed collection, and assemble them into outfits and style boards across devices, aiming for the feel of a contemporary fashion archive rather than a generic 3D demo.
